# bbmp own-format audit (I710)

Date 2026-11-05. Source: github.com/creep-ltx/bbmp docs/replayers.md, csrc/, src/bbmp/backends/formats.py (read via gh api, no local clone). Extensions from the live library DB (Modland rows), because bbmp stores no extensions.

Verification: every covered verdict used two passes. Pass 1 = extension grep over plugins/replayers/*/adapter.c and third_party/nuade player tables. Pass 2 = probe/magic read. The evidence column names which pass was used; rows now also carry RUN evidence from real Modland files (2026-11-05); UNVERIFIED marks what could not be played. Extension collisions (sng, mus, sm1, sm2, mad, dtm, mon, mod) were not accepted from the grep: the colliding plugins probe for other formats' magic, so those formats are uncovered.
