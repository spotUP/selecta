# I1015 hover audit (Mac desktop UI)

Question: which clickable elements draw no hover look when the pointer is over them.
Method: read draw and click functions in `desktop_ui.c`. Not an exported list, so completeness is unverified; see "Unchecked".

## Existing hover mechanisms (reuse these)

- A. Registered box, fill hover: `hover_reg` :973, `desk_hover_move` :13412, `hover_fill_of` :1041. `draw_button_pad` :1075, `draw_button` :1081, `draw_chip` :1087 use it, so all buttons and chips hover.
- B. Ink hover: `hover_ink_of` :993, `row_ink` :1011 (text or icon colour only).
- C. Row fill: `list_row_fill` :1020 (I690b/I1011). Dump lines `plhover` :7388, `searchhover` :7252. It does NOT repaint on pointer move by itself: the row must also be `hover_reg`'d (see `song_row_reg` :2824).
- D. Link underline: `link_hover_mark` :1031.
- E. Tile hover: `d->hover_tile` + `quick_hover_fill` (Home tiles), `hover_shelf1` :2644.
- F. Row "..." icon only while pointer in row: `song_row_reg` :2836.
