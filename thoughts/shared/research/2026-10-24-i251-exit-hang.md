# I251: Amiga play with zero pumps, probe run on FS-UAE (2026-10-24)

Result: NOT reproduced at current main. Every run returned rc=0 and the AmigaDOS script reached ALLDONE.
Rig: own FS-UAE (recipe 2026-10-24-uae-rig-recipe.md), Amiga build of the rebased worktree with fprintf(stdout)+fflush probes
(AmigaDOS has no 2> redirect, so probes went to stdout, captured with >>). Probes: play.c around o.close/engine_destroy/return,
adapter.c rp_start (before/after KP_INIT), rp_close entry/after stop, stop() around KP_END, engine.c destroy/close_slot/sel_live_close.

## Runs and trace tails (identical shape in all three)
1. `play slowrate.mod --output null --seconds 0`; 2. `play slowrate.mod --output paula14 --rate 22050 --seconds 0`;
3. `play play1.mod --output paula14 --rate 22050 --seconds 0` (an M.K. module, so kplayer's has_magic matches).
Tail (runs 1-3):
    callbacks=0 frames=0
    TRACE play before o.close
    TRACE play after o.close, before engine_destroy
    TRACE engine destroy slot
    TRACE engine close_slot before rp_close
    TRACE engine close_slot after rp_close
    TRACE engine destroy slot
    TRACE engine destroy slots done
    TRACE engine destroy end
    TRACE play after engine_destroy, before return
    rc=0 / ALLDONE
4. `play play1.mod --output paula14 --rate 22050 --seconds 2`: same tail, `callbacks=0 frames=44100`, rc=0.

## Stop location
None: no hang. The last probe is play.c after sel_engine_destroy, then rc=0 and the script continued.
No `TRACE kp` line appeared in any run (no rp_start, no rp_close entry, no KP_INIT/KP_END). The replayer closed in close_slot
(slot 0) is therefore not kplayer: the CLI play path never starts the HW kind. The HW start needs the app handover hook
(sel_engine_set_handover is only set in apps/selecta/main.c) and the queued==1 HW rule (engine.c ~1817) drops a HW song that is
not started by the playing path. So `selecta-cli play` cannot reach KP_INIT/KP_END at all, with or without pumps.

## Hypothesis
The I251 hang seen on 6777a81 is either gone at main (the engine/destroy path changed since) or it needs the app path
(apps/selecta with handover, kplayer rp_start -> KP_INIT arming the CIA timer interrupt, then exit without KP_END firing a
pump). The Replay freezes (I219i, I231) also involve a HW start, which `selecta-cli play` never does. Next measurement should
run `selecta` headless (go-log run) with the same probes, and a play with a pump-less HW start, not selecta-cli play.
