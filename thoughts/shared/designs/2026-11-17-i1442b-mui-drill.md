# I1442b MUI: source drill pages (Sources picker, Formats / Artists / Platforms levels, filter field)

MUI 3.8 only. No new MUI class. Every rule (labels, children, up, crumbs, which level the filter reaches, how the find text
reaches the engine) lives in `src/uimodel/drill.c`; the MUI plugin only reads `sel_collection_page` and sends lines.

## 2. Shared code first (drill.c), so no UI reimplements it

Lift from desktop_ui.c into `src/uimodel/drill.c` / `include/selecta/uimodel/drill.h` (pure C99, no engine handle):

```c
/* 1 when the engine filters this level's whole list before windowing (formats, artists, format US name). */
int sel_uim_drill_engine_find(const char* path);
/* 1 when the find field shows on this level: engine-find levels while groups are loaded or a find is active; other group
 * levels only when the whole level is one window (skip 0, n < SEL_DRILL_WINDOW), so a local filter never hides rows. */
int sel_uim_drill_filterable(uint32_t page, const char* path, uint32_t n, uint32_t skip, const char* find);
/* Crumb labels and the path each reopens: source name, kind (Formats / Artists / Platforms / New / DeepSID kinds), up to 2 more. */
uint32_t sel_uim_drill_crumbs(const char* source_name, const char* path, char (*label)[96], char (*cpath)[160]);
/* Splits a route / COLLECTION_OPEN key into source, path, skip and find (inverse of sel_uim_drill_key). */
void sel_uim_drill_key_parse(const char* key, char* source, size_t scap, char* path, size_t pcap, uint32_t* skip, char* find, size_t fcap);
/* The count column text: "N" at the root, "N songs" below it, "" when unknown. */
void sel_uim_drill_count(uint32_t page, const char* count, char* out, size_t cap);
```

The desktop switches its statics to these (pure move, `dui-source-drill` and `dui-source-back` must stay green). The text UI's
`tui_drill_filterable` switches to `sel_uim_drill_filterable` (fixes the Platforms / New gap as a side effect; local filtering for
those levels in the text UI stays out of scope, it just stops offering a filter the engine ignores).

## 3. MUI objects

All reused; no new class, no MUI 4/5 attribute.

- `s->col_crumb`: a horizontal Group of up to 4 `mui_make_button_w` buttons (CTL_COL_CRUMB_BASE + i), text = crumb label, the

- The existing `s->col_list` (Selecta listview, `UPA_List_*`): extra virtual rows "Previous" (top, when skip > 0) and "Next"
  (bottom, when the level holds SEL_DRILL_WINDOW rows), the Mac `drl_rows` shape.

Sources page (`mui_sources_page_group`, ~2061): add `s->src_open` button "Open" (CTL_SRC_OPEN) left of Switch, and set
`sp.double_pick = 1` so a double-click / Return on a row opens it. Open = `mui_route_click(SEL_ROUTE_BROWSE_TILE,
SEL_LIB_ITEM_SOURCE, 0, <source id>, <source label>)`, the same route the Mac Browse source tile (desktop ~10536) and sidebar
source row use. Source id/label come from the `mui_srcs` row (map/mui_sources.c; add a `mui_srcs_id(m, i)` accessor there if the

## 4. State and data flow

New fields in `mui_state` (mirror of the Mac drl_* subset the list needs, nothing more):

```c
uint32_t drl_skip;         /* the window the open level shows (from the key it was opened with) */
char drl_find[64];         /* the find text the level was opened with ("" none); engine-find levels */
uint32_t* drl_ord;         /* visible row indices (local filter); NULL = identity */
uint32_t drl_vn;           /* rows drl_ord holds */
uint32_t drl_filters;      /* sentinel, rebuilds of drl_ord (test hook, like Mac) */
```

Flow per engine serial (the existing `pg->serial != s->col_serial` block, ~2990):

1. `pg->drill` ROOT / GROUPS: walk the triples once into `drl_ord` via a local `mui_drl_filter(s, pg)`: keeps row i when the
   field is empty, the level is an engine-find level (engine already narrowed), or `sel_uim_lfilter_match(label, find)` on
   `sel_uim_drill_label(...)` for a local-filter level. List count = `drl_vn + (skip>0) + (pg->songs >= SEL_DRILL_WINDOW)`.
2. `mui_col_row` for a group page maps list row -> Previous / Next / `drl_ord[row - (skip>0)]`; text =
   `sel_uim_drill_label` + two spaces + `sel_uim_drill_count` (replaces the current `sel_uim_drill_row_label` + bare count).
   DeepSID labels still come out right because `sel_uim_drill_label` calls `sel_uim_drill_row_label` first.
3. Crumbs from `sel_uim_drill_crumbs(pg->title, pg->drill_path, ...)`; texts set only when changed.
4. `drl_skip` / `drl_find` come from `sel_uim_drill_key_parse` of the current route entry key (so Back / Forward to a windowed
   level restore its window without extra state).

Clicks (`CTL_COL_LIST`, group page):

- Previous: reopen same path, skip - WINDOW (floor 0), find kept. Next: skip + WINDOW. Both through `mui_route_click` (a window
  is a history entry on Mac: `drl_open_q` pushes when q is "").
- Group row: unchanged descent (`sel_uim_drill_child`), find cleared (new level starts unfiltered, Mac + text agree).
- Crumb i (CTL_COL_CRUMB_BASE + i): `mui_route_click` with key `sel_uim_drill_key(source, cpath[i], 0, "")`.

## 5. Filter field behaviour (narrow before windowing like the engine)

- Engine-find level (`sel_uim_drill_engine_find(path)`): each change of the field sends
  `COLLECTION_OPEN 7 "<sel_uim_drill_key(source, path, 0, find)>" 1` directly with `mui_engine_line` (quoted like
  `desk_quoted_request`), **no route push** (Mac: the find text is not part of history). Skip resets to 0. The field keeps focus
  and its text across the reload (MUI rebuilds only the list; never re-set the String while it is the active object).
  Rate: one line per change is what the Mac does; on 68k the engine query over 4000+ artists may lag. Debounce is an open
  question (section 9), default none.
- Local-filter level (platforms, platform US id, new, root): rebuild `drl_ord` only, no engine line. Field hidden when the level
  spans more than one window (rule in `sel_uim_drill_filterable`).
- Empty field: engine-find level reopens with find "" (full list, skip 0); local level shows all rows.
- Match rule: `sel_uim_lfilter_match` on the shown label (case-insensitive substring), same as Mac `drl_filter`. The engine side
  uses `drill_name_has`; both already agree on the tests (sections 5 to 7 of tests/dui/source_drill.cmake).

## 6. Keyboard

- Up / Down / Return in the list: the listview's own keys (double_pick = 1 already on col_list); Return on Previous / Next / a
  group row does what the click does.
- Backspace outside a text gadget: Back (existing, I1423), i.e. one level up through history. Inside the field Backspace edits.
- `/` on a drill page with the field shown: activates it (`mui_field_activate(win, s->col_find)`), matching the text UI key. Add
  `/` to the Selecta_Keys window table only while the field is shown; no new action in the shared keybind table unless one for
  "find" already exists (none found by grep in keybind.c / actions.c).
- Esc inside the field: clear text (engine-find level reopens unfiltered) and return focus to the list. Esc must not reach Quit
  (I1359 path already drops an Esc-caused Quit).
- Sources page: Return / double-click on a row = Open.
