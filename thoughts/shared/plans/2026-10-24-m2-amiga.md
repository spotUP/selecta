## Decisions taken with defaults (open, Johan confirms)

- **D-M2-1 nuade float voice API under interrupt.** Default: the CIA/audio interrupt only sets a signal; a high-priority audio task (priority 30) runs `sel_engine_render` and the nuade tick; interrupt code is integer-only (T54). Measure each nuade player's tick on 68020 without FPU (T60); players over one tick get `SEL_RP_NEEDS_FLOAT` and are hidden on no-FPU machines. File the integer voice API request upstream to emoon/nuade in parallel. Alternatives: (a) upstream integer voice API first, block Paula-direct nuade until it lands; (b) require FPU for every float player regardless of measured cost.
- **D-M2-2 plain M.K. .mod on Amiga.** Default: tracked gap in M2. M.K. on Amiga plays only where an adapter claims it (none in M2); `selecta-cli formats --machine amiga` lists `mod (M.K.)` as `unsupported, owner pending`. Ask the nuade M.K. player upstream (author is a friend of Johan). Alternatives: (a) UADE-native ProTracker replayer (M4 HW kind, takes CIA); (b) PS3M native (M4, 020+ only, leaves 68000 empty); (c) libopenmpt 68k build (heavy, float).
- **D-M2-3 F27 split.** Default: M2 ships ToolTypes = CLI = commands (one parser) and task priority (T58). AppIcon, AppWindow, iconify and public/own screen move to M4 with OS file integration (design doc line 75), because they need a window UI. Alternative: ship AppIcon iconify in M2 for the text UI's console window.
- **D-M2-4 paula14 calibration.** Default: one fixed linear table (Eagleplayer 14 Bit Amplifier default, volume 64 high / 1 low) shipped as `paula14` prefs default; per-machine calibration file (`ENVARC:Selecta/paula14.cal`, CyberSound format) loads when present. Alternative: calibration only, no default table.
- **D-M2-5 AHI defaults.** Default: AHI mode from `ahi.device` preferences unit 0 (`AHI_DEFAULT_ID`), rate 28150 Hz on 68020, 44100 on 68040+, from `sel_machine` CPU class; buffer length per CPU class in `sel_prefs` (68000: 8192, 68020: 4096, 68030: 2048, 68040+: 1024 frames). Alternative: fixed 22050 Hz everywhere.
- **D-M2-6 planar tier scope in M2.** Default: probe and tier value only (T50); no planar UI, no copper/blitter scopes in M2 (viz on bitmap surfaces is M4). Alternative: one planar scope in M2.
- **D-M2-7 RENDER fixture on Amiga.** Default: the existing render test plugin plays the RENDER fixture for T59 (libopenmpt is desktop-only; SID and libxmp arrive in M2b). Alternative: pull one M2b adapter (libxmp) forward into M2.
- **D-M2-8 F15 per-replayer config.** Default: `SEL_RP_CONFIG` tag list and library per-song override ship in M2 (T61), as section 1a tags them. Alternative: defer to M2b with the adapters that need it most.

## File layout

- `src/core/amiga/`: `audio_int.c` (CIA-B timer interrupt server, signal only), `audio_task.c` (priority task, render loop), `clock.c` (timer.device ReadEClock; DateStamp fallback under vamos), `dir.c` (Examine/ExNext), `machine.c` (GFX, AUDIO probes, tier), `options.c` (ToolTypes and ReadArgs into one option table generated from `commands.def`).
- `plugins/outputs/paula/amiga/`: Paula voice sink (4 voices, chip RAM samples via `host->mem_alloc(SEL_MEM_CHIP)`), `shadow/` register-log twin for vamos and desktop tests.
- `plugins/outputs/paula14/amiga/` and `plugins/outputs/paula14/common/` (portable split tables, used by the shadow twin).
- `plugins/outputs/ahi/amiga/`: ahi.device double buffer.
- `src/mixer/`: `led.c`, `width.c` (integer stages).
- `plugins/ui/text/amiga/`: `term.c` (raw mode via `SetMode`, `WaitForChar`), `spawn.c`.
- `apps/selecta/`: Amiga build of the shell (`Selecta`).
- `include/selecta/tags.def`: `SEL_RP_MIN_CPU`, `SEL_RP_NEEDS_FLOAT`, `SEL_RP_MEMORY`, `SEL_RP_PRIORITY`, `SEL_RP_CONFIG`, `SEL_OUT_MEM_CHIP`.
- `tests/amiga/run_rig.cmake`: rig driver over the `amiga` MCP (wasabi), label `rig`.

## Phase 4 (I122 to I126): paula14 and AHI PCM outputs

Portable paula14 split tables plus Amiga sink (two channels per side, 14-bit). AHI sink over ahi.device. Shared double buffer in chip RAM swapped on the audio interrupt, buffer length from `sel_prefs` per CPU class (D-M2-5). Routing: RENDER kind and VOICE kind over 4 voices go mixer then `paula14` or `ahi` by prefs. Turns T52, T59 green; extends T54 to the output objects.

## Phase 5 (I127 to I129): LED filter and stereo width

## Deviations

### Phase 0 (I105, I106) deviations

- Flag names (`--stats`, `--led`, `--stereo-width`, `--rp-config`, `--budget-batch`, ...) and goldens under `tests/golden/m2` are placeholders chosen by Phase 0; the implementing rows fix the final names and pin goldens when features land.
- `tests/amiga/run_rig.cmake` drives the rig through the `ami.py` CLI, not the MCP server, and prints `SKIPPED rig not running` when the rig is down. The rig-up path is untested: `ami.py ping` answered "auth failed: bad key".
- Vamos twins and T54 register only when vamos, the cross `nm` and the build/amiga cli exist.
- T60 needs a no-FPU rig (`rig.py start --a1200 --nofpu`) and `SEL_RIG_NOFPU=1`.
- Report: `thoughts/shared/plans/m2-phase0-report.md`.

### Phase 1 (I107 to I111) deviations

- nuade is tagged `SEL_RP_NEEDS_FLOAT` until T60 measures each player's tick on 68020 without FPU. `SEL_RP_CONFIG` is declared but unused until T61 (I135).
- OpenDevice on an absent device never returns under vamos, so the ahi.device and timer.device opens are guarded by a device-list lookup first. Clock falls back to DateStamp under vamos; the ReadEClock path (I110) and ECS/AGA/RTG/AHI detection (I109) are unproven until the rig is back.
- T49 ordering is a500 >= a1200 >= ... (strict a500 > a1200 cannot hold; both tiers hide nuade and openmpt). Goldens are per mode. T50 checks the CLI's real keys (GFX, AUDIO, TIER); `m2_check` accepts upper case.
- No unit test has two plugins with different priority for one format (only nuade lists formats); the priority owner choice is covered only by the single-owner path.
- Report: `thoughts/shared/plans/m2-phase1-report.md`.

### Phase 2 (I112 to I117) deviations

- `cmake/nofloat.cmake` want-list for T54 is cut to `audio_int` and `audio_task` (objects=2); Phases 3 and 4 re-add the paula, paula14 and ahi objects.
- `audio_int.c` and `audio_task.c` compile but are not wired into an Amiga app yet; the `cia_ints=` and `audio_task_ticks=` rig sentinels are unverified. Phase 3 wires them through the Paula sink.
- `cmake/no_float.cmake` now expects 28 engine-side objects (options.c added).
- PRI, BUFFER and LED are prefs rows, not `commands.def` verbs; the parser reads prefs keys for ToolTypes and CLI.
- The icon.library `.info` ToolTypes reader is not written; T58 reads a text fixture (one KEY=VALUE per line). Real `.info` reading is open.
- No desktop twin for T57.
- vamos stubs SetTaskPri. The agent's fallback that wrote `ln_Pri` by hand was removed at merge; T58 under vamos checks `task_pri_requested=`, and the new rig test `rig-task-priority` checks `task_pri=5` on real exec.
- Flake: vamos "path setup failed" on the first run after a rebuild or under `-j2`.
- Commit 2987e49 alone does not build (needs loop.c from c971ab2).
- Report: `thoughts/shared/plans/m2-phase2-report.md`.

### Phase 5 (I127 to I128) deviations

- LED filter and stereo width are integer stages in `src/mixer/stage.c`, applied before the DSP chain. `sel_engine_set_paula_output` bypasses both while the output is real Paula; the Paula output must call it (Phase 3/4 wiring).
- Measured -3 dB point on a generated sweep: 3275 Hz at 44100 and 48000 Hz, 3280 Hz at 22050 Hz. `led_cutoff_hz=` prints the designed constant, not the measurement.
- `selecta-test.mod` renders mono through nuade protracker4, so "width moves the hash" cannot hold on it. On that file T53 checks LED, both knobs together and the golden in both trees, and width 0 equals the plain render. Width-moves-hash runs on stereo `selecta-test-mk.mod`, desktop only (libopenmpt is not in the 68k build). Q46.
- `no-float-engine` expects 29 objects (stage.c added).
- vamos truncates long absolute host paths; T53-vamos runs from the repo root with relative paths. The shared `m2_exec` in `tests/m2/lib.cmake` has the same exposure.
- I129 (commands `filter.led` and `mix.stereo_width`, prefs keys, text UI controls, T8 count) is open.
- Report: `thoughts/shared/plans/m2-phase5-report.md`.
