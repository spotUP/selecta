# M0 skeleton (M0a): build, tag ABI, protocol tables, engine shell, null output, selecta-cli

Implements design doc `thoughts/shared/plans/2026-10-22-architecture-design.md` sections 2 (layering), 3 (commands and events as X-macros), 5 (output plugin tag list), 10 (tag ABI, `sel_host`, `sel_plugin_entry`, registry), 11 (repo layout), 12 (C99, `-Werror`, CMake, 68k toolchain), 13 (protocol round-trip test, tag lint, Amiga smoke) and 14 (M0). RULES.md rules 1 to 4 and the Commands table are the contract.

M0 in the design = skeleton + machine probe + nuade adapter + fixed-point mixer + `wav` + one desktop output + `selecta-cli render` + golden tests. This plan is the first half, **M0a**: everything that does not need a replayer or audio hardware. M0b (machine probe, mixer, nuade adapter, `wav` and `coreaudio` outputs, `render`, golden WAVs) gets its own plan after M0a is `done`.

## Decisions taken in this plan (not open)

- **Date and name.** The next-session prompt named the file `2026-10-23-m0-skeleton.md`; today is 2026-10-22, so the file carries today's date.
- **Toolchain root.** `m68k-amigaos-gcc` 6.5.0b lives in `~/opt/amiga/bin`, not `/opt/amiga` (that holds only binutils). The toolchain file looks in `$AMIGA_GCC_ROOT`, then `~/opt/amiga`, then `/opt/amiga`. RULES.md Commands text fixed in this plan's commit.
- **C runtime on Amiga.** `-mcrt=nix20` (libnix, Kickstart 2.0+, no ixemul). The 68020 baseline runs OS 3.x; no ixemul dependency in a music player. `-m68020 -fomit-frame-pointer -O2`. Verified 2026-10-22: a hello-world built with `-m68020 -mcrt=nix20` (11432 bytes) runs under `vamos -C 68020` and prints `sizeof(uintptr_t)=4`; under the default 68000 CPU the libnix startup raises Alert `00068020` and exits, which is the wanted baseline guard. Every vamos invocation in this plan therefore passes `-C 68020`.
- **Protocol text format.** One line per message: `VERB arg arg ...`. Argument signature per `.def` entry is a string of type letters: `s` string (double-quoted when it contains a space or a quote, `\"` and `\\` escapes), `i` signed 32-bit decimal with optional `+`/`-` prefix kept as a flag (relative), `u` unsigned 32-bit, `t` tag list rendered `{NAME=value,...}` where NAME comes from `tags.def` and value is decimal, hex or a quoted string per the tag's declared type. A trailing `?` marks an optional argument; `*` means repeat the previous letter to end of line. Events use the same codec. This is the remote protocol wire format of section 8; the codec is the one in `src/protocol/codec.c`.
- **Three `.def` tables, not two.** `commands.def`, `events.def` and `tags.def`. The design names only the first two, but `TAGTYPES` (section 3) and the tag lint (section 13) both need the tag names and types from one source; a tag table in a header would be a second definition of each tag (rule 2). `tags.def` lines: `SEL_TAG(ns, name, value, type)`, type one of `INT`, `STR`, `PTR`, `LIST`.
- **Engine behaviour in M0a.** Real: `PLAY`, `PAUSE` (toggle), `PAUSE_PLAYBACK on|off`, `STOP`, `VOLUME v|+d|-d` (0 to 100 integer, clamped), `OUTPUT name`, `OPTION name value` (stored in a fixed table of the section 3 option names, emits `OPTIONS_CHANGED`), `COMMANDS`, `EVENTS`, `TAGTYPES`, `BEGIN`/`END` (batch: events deferred until `END`). Every other verb in `commands.def` returns `ERROR not_implemented <VERB>` and is counted by the ratchet (T8). No verb is left out of the table: clients discover the whole vocabulary from day one, and the ratchet makes the gap visible and non-increasing.
- **Null output.** `plugins/outputs/null/null.c`: PCM sink, pull model, no OS headers, counts frames pulled, exposes the count through `SEL_OUT_STATS` (a `t` tag list with `SEL_OUT_STAT_FRAMES`). It exists to prove the output path and is the only output in M0a.
- **Loaders.** Static registry only (section 10: default for tests). `dlopen` / `LoadSeg` are M2 and M5 work and get their own rows then.
- **Threading.** M0a runs the render path on the calling thread (the CLI pumps). The SPSC queues are built and used (commands in, events out) so the shape is right; the audio thread arrives with the `coreaudio` output in M0b.
- **Formatting and lint.** `.clang-format` (LLVM base, 4 spaces, 100 columns, pointer left). `format` and `lint` targets use `clang-format` / `clang-tidy` when `find_program` finds them, otherwise print one line saying what to install and skip; `-Werror` and `sdk-isolation` always run. Installing them is outside the repo and is under Blocked on me.
- **CI.** `.github/workflows/ci.yml` with the host job (configure, build, ctest) now. The Amiga job needs a bebbo toolchain container image; no image was verified in this session, so the Amiga CI job is row I21 with "image to verify" and the local cross-build (T9) is the M0a gate.
- **Allocation rule.** Everything the engine needs is allocated in `sel_engine_create` (queues, option table, event scratch). `sel_engine_pump` and the render path allocate nothing; `tests/m0/no_alloc.sh` wraps `play-null` with a `malloc` counter (host only, via `DYLD_INSERT_LIBRARIES` shim `tests/m0/count_malloc.c`) and asserts zero allocations after `start`. This is the first instance of the SDK lint in section 12 and lands in I15.

## Phase 1: build skeleton (rows I1 to I3)

Files: `CMakeLists.txt`, `cmake/amiga-68020.cmake`, `cmake/selecta_plugin.cmake`, `.clang-format`, `apps/selecta-cli/main.c` with only `version`.

`cmake/amiga-68020.cmake`:
```cmake
set(CMAKE_SYSTEM_NAME Generic)
set(CMAKE_SYSTEM_PROCESSOR m68k)
set(SEL_AMIGA 1)
set(AMIGA_GCC_ROOT "$ENV{AMIGA_GCC_ROOT}" CACHE PATH "bebbo amiga-gcc install root")
if(NOT AMIGA_GCC_ROOT)
  foreach(cand "$ENV{HOME}/opt/amiga" "/opt/amiga")
    if(EXISTS "${cand}/bin/m68k-amigaos-gcc")
      set(AMIGA_GCC_ROOT "${cand}")
      break()
    endif()
  endforeach()
endif()
if(NOT EXISTS "${AMIGA_GCC_ROOT}/bin/m68k-amigaos-gcc")
  message(FATAL_ERROR "m68k-amigaos-gcc not found; set AMIGA_GCC_ROOT")
endif()
set(CMAKE_C_COMPILER "${AMIGA_GCC_ROOT}/bin/m68k-amigaos-gcc")
set(CMAKE_C_FLAGS_INIT "-m68020 -mcrt=nix20 -fomit-frame-pointer")
set(CMAKE_EXE_LINKER_FLAGS_INIT "-m68020 -mcrt=nix20")
set(CMAKE_FIND_ROOT_PATH "${AMIGA_GCC_ROOT}/m68k-amigaos")
set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY ONLY)
set(CMAKE_FIND_ROOT_PATH_MODE_INCLUDE ONLY)
set(CMAKE_EXECUTABLE_SUFFIX "")
```

Root `CMakeLists.txt` essentials: `cmake_minimum_required(VERSION 3.20)`, `project(selecta C)`, `set(CMAKE_C_STANDARD 99)`, `set(CMAKE_C_EXTENSIONS OFF)`, `add_compile_options(-Wall -Wextra -Werror -pedantic -Wvla)`, `include(cmake/selecta_defs.cmake)`, `include(cmake/selecta_plugin.cmake)`, `add_subdirectory` for `src`, `plugins`, `apps`, and `tests` when `SEL_BUILD_TESTS` (default ON, OFF under the Amiga toolchain because ctest cannot run 68k binaries; T9 runs from the host build dir).

`sel_add_plugin(name kind src...)`: `add_library(sel_plugin_${name} STATIC ${src})`, `target_include_directories(... PRIVATE ${PROJECT_SOURCE_DIR}/include)`, `set_property(GLOBAL APPEND PROPERTY SEL_PLUGINS ${name})`. The registry list `registry_list.c` is generated from `SEL_PLUGINS` at configure time with one `extern const sel_tag* sel_plugin_entry_${name}(uint32_t);` per plugin (each plugin's `sel_plugin_entry` is renamed via `-DSEL_PLUGIN_ENTRY=sel_plugin_entry_${name}` in the static build; dynamic loaders in M2/M5 use the plain name). The `sdk-isolation` target recompiles the same sources as object libraries with `include/` as the only include directory and `-nostdinc`-free but with `-isystem` left to the compiler default; the rule is "no project include outside `include/selecta/`", which the restricted include path enforces.

Automated verification: `cmake -S . -B build/host -G Ninja -DCMAKE_BUILD_TYPE=Debug && cmake --build build/host && build/host/apps/selecta-cli/selecta-cli version` prints `selecta-cli 0.0.1 api 1`. `cmake -S . -B build/amiga -G Ninja -DCMAKE_TOOLCHAIN_FILE=cmake/amiga-68020.cmake && cmake --build build/amiga` builds; `file build/amiga/apps/selecta-cli/selecta-cli` says AmigaOS hunk executable; `vamos -C 68020 -- build/amiga/apps/selecta-cli/selecta-cli version` prints the same line.

## Phase 2: tag ABI and the three .def tables (rows I4 to I7)

`include/selecta/tags.h` (from design section 10, verbatim shape):
```c
typedef struct sel_tag { uint32_t tag; uintptr_t value; } sel_tag;
#define SEL_TAG_END   0u
#define SEL_TAG_MORE  1u
#define SEL_TAG_SKIP  2u
#define SEL_TAG_USER  0x80000000u
enum sel_tag_id {
#define SEL_TAG(ns, name, value, type) SEL_##ns##_##name = (value),
#include <selecta/tags.def>
#undef SEL_TAG
    SEL_TAG_ID_COUNT_MARKER_ /* not a tag */
};
typedef enum sel_tag_type { SEL_TT_INT, SEL_TT_STR, SEL_TT_PTR, SEL_TT_LIST } sel_tag_type;
uintptr_t      sel_tag_find(const sel_tag* list, uint32_t tag, uintptr_t def);
const sel_tag* sel_tag_next(const sel_tag** iter);   /* walks END / MORE / SKIP, returns NULL at END */
uint32_t       sel_tag_count(const sel_tag* list);
const char*    sel_tag_name(uint32_t tag);           /* "OUT_NAME", NULL for unknown */
int            sel_tag_type_of(uint32_t tag, sel_tag_type* out);  /* 0 unknown */
```

Namespaces (section 10, 0x1000 blocks): `PLUGIN` 0x0100 (KIND, ID, VERSION, TAGS), `RP` 0x1000, `OUT` 0x2000, `DSP` 0x3000, `VIZ` 0x4000, `UI` 0x5000, `CONV` 0x6000, `SRC` 0x7000, `META` 0x8000, `MACHINE` 0x9000, `HOSTQ` 0xA000. M0a fills `PLUGIN_*`, `OUT_*` (NAME, SINK, RATES, CHANNELS, LATENCY_MS, OPEN, CLOSE, SET_SOURCE, VOICES, STATS, STAT_FRAMES, DIRECT_VOLUME, HEADPHONES), the `META_*` list from section 4 (TITLE, AUTHOR, FORMAT, CHANNELS, PATTERNS, INSTRUMENTS, SAMPLES, SUBSONGS, DURATION_MS, MESSAGE, SIZE, YEAR, RELEASE, SID_MODEL, STIL), and `HOSTQ_API_VERSION`. Other namespaces get their rows when their plugin kind lands; the block numbers are reserved in a comment at the top of `tags.def` so nobody renumbers.

`commands.def`: `SEL_CMD(id, args)`, one row per verb in design section 3, including the protocol additions (OPTION family, QUEUE_* with ids and versions, QUEUE_CHANGES, SNAPSHOT_QUEUE, DEVICE_*, PLAY_QUERY, QUEUE_ADD_QUERY, BEGIN, END, COMMANDS, EVENTS, TAGTYPES, IDLE, STICKER_*, PAUSE_PLAYBACK, AUTH, RESHUFFLE, SCOPE, NEXT_ALBUM, PREV_ALBUM, UNDO, REDO, SHUFFLE, PREF_GET, PREF_SET) and `UI_SWITCH`. The section lists `BEGIN`/`END` and `COMMAND_LIST_BEGIN`/`COMMAND_LIST_END` as the same feature in two paragraphs: the table carries `BEGIN` and `END` only (one definition per concept); the design doc gets a one-line correction in the same commit. The count is whatever `grep -c '^SEL_CMD(' include/selecta/commands.def` says after the table is written; it is read by CMake, never retyped into a test.

`events.def`: `SEL_EVT(id, args)`: STATE s, SONG_OPENED t, SONG_ENDED, POSITION uuu u, VOICE u t, OUTPUT_CHANGED s, QUEUE_CHANGED u, QUEUE_HISTORY uu, LIBRARY_RESULT t, VIEW_CHANGED s t, VIEW_ROWS t, OPTIONS_CHANGED s s, PREFS_CHANGED s s, SEEKED u, SCROBBLE_DUE, ALBUMART u t, VOLUME i, ERROR s s?, LOG s.

`protocol.h` codec API:
```c
typedef struct sel_message { uint32_t kind; /* 0 cmd, 1 evt */ uint32_t id; uint32_t argc; sel_arg args[SEL_MAX_ARGS]; } sel_message;
int  sel_codec_encode(const sel_message*, char* out, size_t cap);     /* bytes written or -1 */
int  sel_codec_decode(const char* line, sel_message* out, char* strpool, size_t poolcap); /* 0 ok, else SEL_CODEC_E_* */
```
`SEL_MAX_ARGS` = 8 (largest signature in the tables; a static assert generated from the `.def` files checks it). Tag-list arguments decode into `strpool` as a `sel_tag` array plus string storage; no allocation.

Red tests written in this phase: T1, T2 (fail: no `roundtrip`, `commands` subcommands yet), T5 (fails: no registry), T6 (fails: no `abi`).

Automated verification: build green on both toolchains; `tests/abi/sel_host.*.txt` do not exist yet (T6 red).

## Phase 3: codec and CLI reflection (rows I8 to I10)

`src/protocol/codec.c`: tables generated from the `.def` files: `static const char* const k_cmd_names[]`, `k_cmd_args[]`, same for events, name lookup by linear scan (the table is under 100 entries and this runs per command, not per sample). Encoding and decoding per the format decision above. `roundtrip` in `main.c`: for every command and event, build a sample message from its signature (`s` -> `"a b"`, `i` -> `-7`, `u` -> `42`, `t` -> `{META_TITLE="x",META_CHANNELS=4}`), encode, decode, compare, count.

Automated verification: T1 and T2 green; `selecta-cli commands` prints `VERB args` lines; `selecta-cli tagtypes` prints the `META_*` names. The CMake-derived counts are the expectations.

## Phase 4: engine shell and the script test (rows I11 to I13)

`src/engine/engine.c`:
```c
struct sel_engine { sel_state state; sel_spsc cmd_q; sel_spsc evt_q; sel_option options[SEL_OPTION_COUNT]; const sel_host* host; const sel_tag* output; void* output_state; uint32_t in_batch; uint32_t render_calls; };
sel_engine* sel_engine_create(const sel_host*, const sel_engine_config*);   /* all allocation here */
void        sel_engine_send(sel_engine*, const sel_message*);               /* enqueue only */
uint32_t    sel_engine_pump(sel_engine*, sel_event_sink fn, void* ctx);     /* drain commands, dispatch, deliver events; returns events delivered */
const sel_state* sel_engine_state(const sel_engine*);
uint32_t    sel_engine_render(sel_engine*, int16_t* stereo, uint32_t frames);  /* silence in M0a; counts calls */
```
Dispatch is a `switch` over `sel_cmd_id` generated by including `commands.def` with a macro that emits `case SEL_CMD_##id: return cmd_##id(e, m);`; the handler for every unimplemented verb is one shared function `cmd_not_implemented` selected by a second X-macro list `SEL_CMD_IMPLEMENTED(id)` kept in `engine.c`, and the ratchet subcommand prints the complement. `BEGIN` sets `in_batch`, `END` clears it and flushes the deferred `OPTIONS_CHANGED` / `VOLUME` events once each.

`selecta-cli script <file>`: reads lines, decodes, sends, pumps after each line, prints every event with the codec. `tests/m0/basic.sel`:
```

PAUSE
STOP
FOO
SEEK 10
BEGIN
VOLUME 10
VOLUME 20
END
```
`tests/m0/basic.expected`:

## Phase 5: registry, null output, plugin lint, ABI goldens (rows I14 to I18)

`include/selecta/host.h`:
```c
#define SEL_API_VERSION 1u
enum { SEL_MEM_FAST = 0, SEL_MEM_SAMPLE = 1 };
enum { SEL_LOG_ERROR = 0, SEL_LOG_WARN, SEL_LOG_INFO, SEL_LOG_DEBUG };
typedef struct sel_host sel_host;
struct sel_host {
    uint32_t size;          /* sizeof(sel_host) of the host build; a plugin checks before touching a later field */
    uint32_t api_version;   /* SEL_API_VERSION */
    void*    (*mem_alloc)(const sel_host*, size_t size, uint32_t kind);
    void     (*mem_free)(const sel_host*, void* p);
    int32_t  (*read)(const sel_host*, void* file, void* buf, uint32_t n);
    void     (*log)(const sel_host*, int level, const char* msg);
    uint32_t (*clock_ms)(const sel_host*);
    const struct sel_voices* (*voices)(const sel_host*);
    const char* (*config_get)(const sel_host*, const char* key, const char* def);
    int      (*query)(const sel_host*, const sel_tag* ask, sel_tag* answer);
    void*    ctx;
    /* append only below this line; never reorder, never remove */
};
```
`selecta-cli abi` prints `sel_host size=<n>` and one `field offset=<n>` line per field in declaration order; the goldens under `tests/abi/` are generated once per architecture, reviewed by eye against the struct, and committed. T6 fails on any reorder or insertion before `ctx`. Appending a field changes `size` and the golden in the same commit, which is the intended ceremony.

`include/selecta/plugin.h`: `const sel_tag* SEL_PLUGIN_ENTRY(uint32_t host_api);` with `SEL_PLUGIN_ENTRY` defaulting to `sel_plugin_entry`; descriptor tags `PLUGIN_KIND` (`SEL_PLUGIN_KIND_OUTPUT` = 2, replayer 1, dsp 3, viz 4, ui 5, conv 6, src 7, integration 8, scripting 9), `PLUGIN_ID`, `PLUGIN_VERSION`, `PLUGIN_TAGS`.

`plugins/outputs/null/null.c`: descriptor plus `null_open(const sel_host*, uint32_t rate, uint32_t channels) -> state`, `null_close`, `null_set_source(state, sel_pcm_pull fn, void* ctx)`, `null_pump(state, frames)` reachable through `SEL_OUT_PUMP` (M0a-only tag for sinks with no clock of their own; `wav` reuses it in M0b), `null_stats(state) -> const sel_tag*` with `OUT_STAT_FRAMES`. `play-null` opens the registry's `null` output, sets the engine render as source, pumps `--frames` in blocks of 512, prints `pulled=<n> render_calls=<k> rate=<r>` from the plugin's stats and the engine's counter.

`src/engine/registry.c`: `sel_registry_init(const sel_host*)` calls every entry in the generated list, stores the descriptor, and `sel_registry_lint(report)` walks each descriptor and its `PLUGIN_TAGS` sub-list with `sel_tag_next`: unknown tag (no `tags.def` row) and duplicate tag within one list are counted and named. `-DSEL_TEST_BAD_PLUGIN=ON` compiles a second descriptor in `tests/m0/bad_plugin.c` with tag `0x2FFF` so the negative path is proven (T5 second half, run as its own ctest `registry-tags-negative` from a separate build dir `build/host-bad`).

`tests/m0/count_malloc.c`: interposes `malloc`/`calloc`/`realloc`, counts calls after the process writes `SEL_ALLOC_FREEZE` to stderr (the CLI prints it right after `sel_engine_create` + output open); `no_alloc.sh` runs `play-null` under the shim and fails if the count after the marker is not 0.
