## Decisions taken in this plan (not open)

User decisions (2026-10-23, research file): spectrum and note-dots join M1.3; phase view, crossfade and the crossfeed DSP work only on the mixed path (AHI and desktop) and report `unsupported_path` through a capability on Paula-direct. The rest are defaults chosen here:

- **Viz taps, one mechanism.** The engine fills a viz frame every 20 ms of rendered audio (882 frames at 44100 Hz; at other rates `rate / 50`) into a triple buffer the pump thread publishes in the snapshot (`sel_state.viz`, type `sel_viz_frame` in new `include/selecta/viz.h`). Contents: per voice (up to 32): peak (Q15), VU level (Q15), period or pitch, instrument, note on flag; per voice scope of the last 256 mixed frames (int16, post-volume, pre-pan); post-mix stereo ring of 1024 frames (phase view); 16 spectrum bands (Q15). The audio thread writes into preallocated buffers only; no allocation (T26 extended). UIs and future viz plugins read only this frame. VIZ tags 0x4000 get the rows a visualizer plugin needs later (`VIZ_NAME`, `VIZ_OPEN`, `VIZ_FRAME`, `VIZ_CLOSE`); M1.3 text UI panels are built into the text UI and read the same frame, they do not need a viz plugin.
- **VU ballistics.** Peak per 20 ms block; attack instant; release: `level -= level >> 3` per block (about 26 dB/s); no hold. Integer only.
- **Spectrum.** 256-point integer radix-2 FFT in Q15 on the post-mix mono sum, Hann window from a generated table, 16 log-spaced bands from 43 Hz to 16 kHz, magnitude via an integer sqrt. Computed on the pump thread from the published PCM ring, not on the audio thread. Skipped on machines whose `sel_machine` CPU class is below 68030 (capability `spectrum=0`).
- **Note dots.** Text UI panel from the per-voice pitch and note-on flags (OCP style: one row per voice, dot column = pitch on a 96-semitone scale).
- **Pattern scroller.** New replayer tags `RP_TRACKER_INFO (0x1011, PTR)` and `RP_TRACKER_CELLS (0x1012, PTR)` with `sel_rp_tracker_info` (orders, patterns, rows in pattern, channels) and `sel_rp_cell` (note 0..120 or 0, instrument, volume column, effect, param) in `replayer.h`. nuade adapter maps nuade `tracker_info` and `tracker_cells`; openmpt adapter maps `openmpt_module_get_pattern_row_channel_command`. Called on the pump thread only (same rule as RP_POSITION: the slot owner thread; for a published slot the pump reads cells through a request the audio thread answers between render calls, the I56 pattern). Players without the hooks: panel says `No pattern data`.
- **Mute, solo.** Engine owns a 32-bit mute mask. VOICE kind: the mixer skips muted voices (mixed path) and the Paula-direct backend sets volume 0 for them. RENDER kind: new optional hook `RP_MUTE (0x1013, PTR)` (`openmpt_module_ext` interactive `set_channel_mute_status`). `MUTE voice on|off|toggle` (voice is 1-based in the protocol), `SOLO voice` mutes all others, `SOLO 0` clears. Event VOICE "ut" reports the mask.
- **Pitch and tempo.** `PITCH cents` range -1200..1200; VOICE kind scales the resample step by a Q16 factor from a generated 2^(c/1200) table (2401 entries; no float); Paula-direct scales the period by the inverse factor. `TEMPO percent` range -50..100; VOICE kind scales the scheduler tick interval; RENDER kind uses the openmpt interactive `set_pitch_factor` / `set_tempo_factor` through new optional hook `RP_SET_SPEED (0x1014, PTR)`.
- **Loop detect, repeat, fade.** `REPEAT off|one|all` (all = queue wraps; one = the song loops forever; off = default). Options (in the `SEL_OPTIONS` X-macro): `loops` (default 1: end at the first LOOPED), `fade_ms` (default 3000, 0..30000), `max_song_ms` (default 0 = off; when set, a song that never loops or ends fades at that time), `silence_ms` (default 5000, 0 = off; threshold |s| < 16). A fade multiplies the slot output by a Q16 gain that falls linearly to 0 over `fade_ms`, then the song ends. SONG_ENDED gets a reason field (`end`, `loop`, `max_length`, `silence`, `stopped`), an events.def change (args `"s"`). stop-after-current and stop-after-queue (options from M1.1) are wired here.
- **Crossfade and gapless.** `OPTION crossfade <ms>` 0..10000, default 0 = gapless. The next song is prepared into the idle slot `max(crossfade, 2000)` ms before the end is expected (end, loop point, or `max_song_ms`), so gapless needs no extra work beyond preparing early. During a crossfade both slots render and the mixer sums them with the equal-power table (outgoing `cos`, incoming `sin` in Q16, 257 entries, interpolated). Crossfade starts when the outgoing song begins its fade (loop or max length) or `crossfade` ms before a real end the replayer reports with `RP_POSITION`/duration; songs with no known end crossfade from their fade start only.
- **Path capability.** The snapshot carries `mixed_path` (1 when the output takes PCM from the mixer, 0 when it owns voices through `SEL_OUT_VOICES`). On 0, `OPTION crossfade` non-zero, `DSP <any> on` and the phase panel answer or show `unsupported_path`.
- **Sleep timer and alarm.** `SLEEP_TIMER minutes` (0 cancels, max 1440): at expiry the engine ramps volume down over 10000 ms, pauses, and restores the set volume so the next PLAY is at full level. New verb `ALARM "s"`: `HH:MM` 24-hour local time or `off`; at the time, PLAY (resume, or start the queue) with volume rising from 0 over 30000 ms. One alarm; it re-arms daily until `off`. The engine reads a wall clock through a new host query `HOSTQ_LOCAL_TIME` (core pal, all three OSes); tests use `--clock fake`. Events `OPTIONS_CHANGED sleep_timer <ms left>` and `OPTIONS_CHANGED alarm <HH:MM|off>`.
- **Sample export.** New verbs `SAMPLE_LIST ""` (replies one `SAMPLE n len loop_start loop_len rate name` line per sample, then `OK`) and `SAMPLE_EXPORT "us"` (sample number, path; format by extension `.wav` or `.8svx`; anything else `ERROR range SAMPLE_EXPORT`). New optional replayer hook `RP_SAMPLE_GET (0x1015, PTR)` returning a `sel_rp_sample` (pointer to 8- or 16-bit PCM, length, loop start and length, base rate, name). nuade: the adapter has no sample hook upstream, so it builds the catalogue from the voices shim (every distinct `NuadeSample` data pointer the players hand to `nuade_voice_play`/`queue`, recorded in order of first use) on a scan instance opened on the pump thread and skip-run to the song end or 10 minutes; names come from `add_instrument` where the player gives them. openmpt: `RP_SAMPLE_GET` through libopenmpt's internal `CSoundFile` sample table (`module_impl` access from the adapter, no change to libopenmpt). Writers in `src/library/export/{wav.c, svx.c}`; base rate 8287 Hz for MOD-family samples (PAL C-3), the replayer's value otherwise.
- **Crossfeed DSP.** DSP plugin ABI rows in tags.def DSP 0x3000 (`DSP_NAME`, `DSP_OPEN`, `DSP_PROCESS`, `DSP_CLOSE`, `DSP_PARAM`); `include/selecta/dsp.h`; chain of fixed length 4 in the engine after the mixer, before the output, desktop and AHI only. Built-in `crossfeed` plugin: integer Bauer-style, bleed delayed 14 frames at 44100 Hz (scaled by rate), one-pole low-pass at 700 Hz, bleed gain -4.5 dB, direct path compensated so mono passes at unity; coefficients generated by `tools/gen_dsp_coef.c` per supported rate. New verb `DSP "ss"`: `DSP crossfeed on|off`. `SEL_OUT_HEADPHONES` = 1 from an output turns crossfeed on at start unless the user pref `dsp.crossfeed` says `off`.
- **Text UI.** Keys (default bindings, M1.2 table): `v` cycles the viz panel (scopes, VU, spectrum, note dots, phase, off), `P` toggles the pattern scroller, `1`..`9` toggle MUTE of voice n, `0` clears SOLO, `S` SOLO cursor voice, `+`/`-` PITCH 100, `>`/`<` TEMPO 10. Scopes and phase view draw with Unicode braille cells when the terminal is UTF-8, else ASCII `.:|`; colours from the theme.

## Deviations

### Phase 1 (rows I85 to I87, branch worktree-agent-ae23ccc3fbc089dee)
- `render --viz-dump` still needs `--output <wav>`; the T40 command in the plan omits it, so the test passes it.
- VU release is `level -= max(1, level >> 3)` so small levels reach 0.
- Extra ctest entries `viz-vu` and `viz-spectrum`; the phase, VU and spectrum unit tests are host only (they use `math.h` for reference values).
- Viz blocks close at the end of each `sel_engine_render` call, not at exact block edges. This keeps golden renders and RENDER-kind call counts unchanged. In dump mode the CLI pulls `rate/50` frames per call so the dump is exact; with unaligned callers the voice taps can lead the block edge by up to one call.
- Spectrum bands take the maximum over FFT bins (172 Hz per bin at 44100 Hz), so the lowest bands share bins.
- On m68k the triple-buffer swap is a plain volatile exchange; elsewhere `__atomic_exchange_n`. The spectrum is skipped below a 68030.
- Memory: about 16 KB per mixer slot and about 70 KB in the engine. no_float object count is 23.

### Phase 2 (rows I88 to I89, branch worktree-agent-aed727b550d9fa4be)

- nuade does not open the plain M.K. test module, so T41 reads `selecta-test.mod` through nuade and `selecta-test-mk.mod` through openmpt.
- Note numbering differs between the adapters: for MOD period 428 openmpt reports note 61 and nuade note 25 (36 semitones apart). `tests/m13/pattern.expected` records the raw values. This is a defect, not a choice: `sel_rp_cell.note` needs one scale. Fixed in row I89a: the libopenmpt scale (1 = C-0, MOD period 428 = 61) is canonical, the nuade adapter maps to it.
- The openmpt adapter maps effects through a ProTracker-only table; other effect commands read as 0.
- nuade reports `patterns = 0`; its order count is probed up to 4096.
- `sel_engine_tracker_info` and `sel_engine_tracker_cells` call the replayer on the caller's thread, so they are valid from the script driver only. The pump-thread request path for a published slot (I56 pattern) lands with the pattern panel in Phase 6 (I101), before any front end with a separate audio thread reads cells.
- Phase 3a: T42 `SOLO 2` expects mask 0x0d; the plan's 0b1011 was a typo. SOLO clamps the mask to the channel count from tracker geometry, because openmpt reports 0 voices.
- Phase 3a: `render --script` added to drive verbs mid-render. In script mode ERROR events print to stdout and do not fail the render.
- Phase 3a: no Paula-direct volume path exists in code, so nothing was done there.
- Phase 3a: openmpt mute is tested as "differs from unmuted" only, no golden.
- Phase 3a: red reason was the missing `--script` option, not a wrong mask.
- Phase 3a: `pitch_factor_q16=65536` is a placeholder in `apps/selecta-cli/render.c`; I92 replaces it with the engine value.
