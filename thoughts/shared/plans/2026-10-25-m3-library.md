## Finish line

M3 is done when every test below is green through the named entry point, the sentinel proves the new code ran, the spec number holds, and no test touched the live network. Command:

```
cmake --build build/host && nice -n 19 ctest --test-dir build/host -L m3 -j2 --output-on-failure
nice -n 19 ctest --test-dir build/host -R ratchet --output-on-failure
cmake --build build/amiga && nice -n 19 ctest --test-dir build/host -R 'amiga-library|rig-library' -j2
```

Every network test runs with the net guard (T67): `SELECTA_NET_ALLOW=127.0.0.1` makes any non-loopback connect fail with `net_blocked=1`, and `SELECTA_NET_MAP=<host>=http://127.0.0.1:<port>` points every external host at the fixture server (D-M3-6). Each fixture test also asserts the fixture server's request log (method, path, headers, body hash), so a test that silently read a stale cache fails.

## Decisions taken with defaults (open, Johan confirms)

- **D-M3-1 SQLite vendoring.** SQLite is not in `third_party/` (has only `libopenmpt`, `nuade`, `patches`). Default: vendor the amalgamation (`sqlite3.c`, `sqlite3.h`) of the newest release at vendoring time into `third_party/sqlite/` with `VERSION` and the sqlite.org SHA3-256 recorded; CMake target `selecta_sqlite` with `SQLITE_ENABLE_FTS5`, `SQLITE_ENABLE_MEMSYS5`, `SQLITE_OMIT_LOAD_EXTENSION`, `SQLITE_THREADSAFE=0`, `SQLITE_DEFAULT_MEMSTATUS=0`, `SQLITE_DQS=0`; same source on desktop and 68k. Alternative: system SQLite on desktop, vendored only for 68k.
- **D-M3-2 Library thread model.** Default: one library worker (desktop thread via `src/engine/thread.h`; Amiga subtask at a priority below the main loop) owns the only DB connection; the engine forwards LIBRARY_* and the other library verbs over an SPSC request queue and receives rows over a result queue, emitting `LIBRARY_RESULT`; SQLite runs on a memsys5 heap allocated once at start and sized from `sel_machine` (rule 4: no allocation after start). Alternative: synchronous library calls inside `sel_engine_pump()`.
- **D-M3-3 Floating point in the library.** Default: SQLite (bm25 ranking, REAL columns) and the desktop R128 analyser may use double; both run on the library worker, never in the engine render path or under interrupt; T54's object list excludes them by target. On 68k without FPU this is soft-float in the library task. Alternative: `SQLITE_OMIT_FLOATING_POINT` on 68k (loses bm25 ranking; FTS5 order falls back to rowid).
- **D-M3-4 HTTP and TLS.** Default: one own HTTP/1.1 client (`src/library/net/http.c`) over a socket table in `src/core/<os>/net.c` (POSIX sockets, Amiga bsdsocket.library), TLS as a stream wrapper on desktop from vendored mbedTLS 3.6 LTS (`third_party/mbedtls`), CA store from the OS (macOS Keychain export, `/etc/ssl/certs` on Linux) plus `SELECTA_CA_FILE`; the Amiga build is plain HTTP only and reaches HTTPS-only sites through the DEViLBOX mirror (design doc section 16). One client, both tiers. Alternative: libcurl on desktop and the own client on Amiga (two clients for one job).
- **D-M3-5 FTP.** Default: passive-mode FTP (USER anonymous, TYPE I, SIZE, PASV, RETR) on both tiers for `ftp.modland.com` and the plain amigascne mirror, so an Amiga reaches Modland directly without the DEViLBOX proxy. Alternative: HTTPS mirrors only, no FTP.
- **D-M3-6 Fixture servers.** Default: one Python 3 standard-library fixture server `tests/net/fixture_server.py` (HTTP/1.1 with chunked, Range, redirect and delay knobs, TLS with a test CA generated at configure time, minimal passive FTP), serving recorded responses from `tests/net/fixtures/<host>/`, writing a request log that every test asserts; ctest `FIXTURES_SETUP net-fixture`, `RESOURCE_LOCK net-fixture`; net guard env vars `SELECTA_NET_ALLOW`, `SELECTA_NET_MAP` read by `src/core/<os>/net.c` only. Alternative: a C fixture server built as `selecta-cli fixture-serve`.
- **D-M3-7 Archive decrunch on desktop.** Default: miniz (zip, gzip), lhasa (lha/lzh), an unlzx C port (lzx), temisu's `ancient` (C++, xpk and PowerPacker) as adapters in `third_party/` with patches in `third_party/patches/`; Amiga uses xad/xfd libraries through `src/core/amiga/`. Alternative: `ancient` for every format it covers (one C++ dependency for more formats).
- **D-M3-8 Stream decoders.** Default: minimp3 and stb_vorbis as RENDER-kind replayer plugins reading from a byte stream (URL, pipe, file), tagged `SEL_RP_NEEDS_FLOAT` so the M2 machine filter hides them on no-FPU Amigas. Alternative: system libmpg123 and libvorbis on desktop.
- **D-M3-9 Loudness target and modes.** Default: EBU R128 integrated loudness, target -18 LUFS (ReplayGain 2.0 reference), pref `mix.loudness` = `track` (default) / `auto` (adaptive leveler when no gain) / `off`; peak limiter ceiling -1 dBFS in the mixer; analyser in double on the desktop library worker (D-M3-3); album and playlist gain modes stay "later" per section 6a. Alternative: -14 LUFS (streaming-service level).
- **D-M3-10 New verbs, born implemented.** Default: `LIKE on|off`, `KEEP on|off`, `FLAG wrong|skip on|off [note]`, `NOTE text`, `FOLDER_ADD name parent`, `FOLDER_MOVE id parent`, `FOLDER_DEL id`, `PLAYLIST_MOVE id folder`, `LIBRARY_SCAN paths`, `LIBRARY_SYNC source`, `VIEW_SAVE name query`, `VIEW_SOURCE queue|playlist|query|home`, `SHARE song|playlist|position`, `RADIO seed`, `ANALYSE query`, each a `commands.def` row with a codec round trip (section 13 protocol test). Alternative: carry these through STICKER_* (rejected by the design: ratings, liked, cues and notes use typed tables).
- **D-M3-11 Share link format.** Default: `selecta://song/<source>/<path>[?sub=<n>&t=<ms>]`, `selecta://playlist/<source>/<id>`, `selecta://view/<urlencoded query>`; `selecta <link>` and `selecta-cli open <link>` accept them; the DEViLBOX URL form follows the layout I139 records; OS URL-scheme registration waits for the M5 SDL app bundle. Alternative: register the scheme in M3 through a minimal macOS app bundle.
- **D-M3-12 DEViLBOX account.** Default: `selecta-cli devilbox login <user>` calls `POST /api/auth/login` and stores the JWT in the profile directory (`<config>/devilbox.token`, mode 0600), never in the library DB; reads need no token. Alternative: token only from the `SELECTA_DEVILBOX_TOKEN` env var.
