# I195f: chained Ogg streams in the live stb_vorbis path; Amiga -Wmaybe-uninitialized in stb_vorbis.c

Plan: 2026-10-25-m3-library.md phase 11; design doc section 1a.

Defect: stb_vorbis's pushdata decoder treats the three header packets of a second logical stream (new BOS page, new
serial) as bad packets and skips them, then decodes the new stream's audio with the OLD codebooks, and the adapter's
title/artist/album stay the first track's.

Fix (plugins/replayers/stb_vorbis/adapter.c): pull_live checks for "OggS" with the BOS flag at the read position and
calls rechain(): opens a new pushdata decoder on the window (never blocks: incomplete headers render silence and
retry), closes the old one, re-reads channels and rate (a rate change restarts the resampler), and reads the Vorbis
comments into the idle half of a two-slot tag store, then flips md_cur (rp_metadata reads the live slot, so another
thread never sees a half-written string). Title reaches the UI through the existing rp_metadata -> song.meta path.

Test: ctest stream-live-ogg-chained (tests/net/stream_chained.cmake). Fixture tests/m3/stream/chained.ogg (12 KB, two
1 s streams, 440 Hz "Chain One" + 880 Hz "Chain Two"), regenerated by tests/m3/stream/make_chained_ogg.sh (ffmpeg
native vorbis; serials are random per run, so a regenerated file differs byte-wise). Served over HTTP via slow_server.py
(100%), played with selecta-cli script; new directive `@title` prints `TITLE text=` from the engine state. Asserts
title Chain One before and Chain Two after the join, render sizes, and non-silence in both parts.
Fail-before (rechain disabled): "title did not change at the chained stream (TITLE text=Chain One, want Chain Two)".
Pass-after. With stream-live*, stream-decode, stream-tags etc. (12 tests matching "stream-|stb|ogg") all pass.

Amiga warning: real. get_seek_page_info (stb_vorbis.c) ignored getn()'s result; on a short memory read header[] and
lacing[] stayed uninitialised and were parsed. Fixed in the vendored copy by failing the probe on a short read (two
lines, commented, noted in third_party/stb_vorbis/VERSION). build/amiga now builds with zero stb_vorbis warnings.

Open: the ring may hold a 66000-byte window, so a chain whose headers exceed what the window can show would end the
stream (rechain returns -1 only when the window is full and still incomplete; practically setup headers are < 10 KB).
Not covered: a chain with a different sample rate (code path exists, untested).
