## Title fallback answer

The engine title DIFFERS from the desktop title. Engine: `coll_song_row` f[1] = `IFNULL(s.name,'')` (src/library/db/items.c:373, SONG_COLS),
an empty string when the catalogue has no name, no fallback. Desktop: plugins/ui/desktop/desktop_ui.c:4750 seeds `pls_title[i]` with
`path_base(key)` (file name), and :4626-4628 (pls_briefs_follow) overwrites it only when the brief title `r[0] != '\0'`. So an
unnamed song shows and sorts (desktop_ui.c:4810 col_order_cmp) by its file name. `sel_coll_title` applies the same rule (title,
else text after the last '/' of the key), and the sort and filter use it, so Title order does not change. Tested (row with
empty title sorts as "alpha.mod" and matches filter "alpha").
