## Changes
- plugins/ui/text/manifest.c (new): static tags (SEL_UI_NAME, SEL_UI_VIEW_STYLES), id "text", SEL_PLUGIN_MODULE "sel_text_ui".
- plugins/ui/text/CMakeLists.txt: on Amiga `sel_add_plugin(text_ui 5 text_ui.c AMIGA_MANIFEST manifest.c SEG_IMPORTS)`; the seg links
  selecta_textui_seg (grid, quote, sizeprobe, locale, amiga term/spawn) and selecta_uimodel_seg. Non-Amiga build unchanged.

  not a Selecta module` (Players/sel_<id>_ui); an unknown id keeps "is not registered".
- tests/amiga/run_text_ui_module.cmake + two ctest entries in tests/CMakeLists.txt: text-ui-on-demand-vamos, ui-module-missing-vamos.
