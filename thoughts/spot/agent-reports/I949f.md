## Host test
`mui-open-compact-reach` (mui_contract_test open-compact-reach). Drives the chain mui_open runs on a 640x256 screen:
mui_open_ladder step 0 -> mui_layout_map_panel with the step's layout size (as mui_layout_for_screen) -> compact class,
door rail sidebar (mui_sidebar_rail_builds sentinel), compact player band <= 36 rows (mui_player_band_compact_builds sentinel),
ladder sentinel mui_open_ladder_calls. Also: a refused step 0 falls to the mini layout (width 599, not compact).
Source checks: mui_open loops the ladder, mui_layout_for_screen lays out from the step, side_rail and the band take
mui_screen_compact(), the "window minimum" log line exists.
mui_open itself is Amiga-only, so the host test cannot call it; the measured root minimum is a rig number.
