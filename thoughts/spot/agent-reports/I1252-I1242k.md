## I1242k "no replayer claims" triage (no code change; nothing cheap left)
Claimed extension tables (grep of every SEL_RP_EXTENSIONS) against the list; the ledger text is partly stale:
- ay, mp2, mp3: already claimed (bbmp_ay, gme; minimp3 "mp3,mp2"). The failing samples were `ay.pt3` and `mp2.usflib`/`mp3.usflib`: the Amiga prefix rule read the file name prefix as the extension. Not a gap (see below, prefix finding).
- mc, sj (zxart): samples `Mc.Floyd_-_...pt2`, `SJ.Lex_-_...pt3`: same prefix artefact, real suffix is pt2/pt3.
- bds: sample `bds.instr`, IFF-SMUS instrument file, same artefact.
- sm1, sm2: FAC SoundTracker drum kits, companion data read by bbmp_fac from the song folder, not songs. No claim wanted.
- stp, psm (zxart/Spectrum): claimed by the zxtune module, but it builds only with SELECTA_ZXTUNE_SRC (a zxtune checkout, GPL); not in this tree, so unverifiable here. `m` is claimed by 98fmplayer (a zxart `.m` is a different format; unchecked).
- max: nuade has a maximumeffect player (extension max), but Modland "MAX.AlloAllo level5" (9264 bytes, header `2d2d2d0f 2d2d2d14 ...`) is rejected by mxe_module_parse (first list offset 0x2d2d2d14 exceeds the size). Likely a mis-filed or different-variant file, not a missing claim. Needs a look at what that file is.
- med: Modland "Music Editor" `whomp!.med`, magic `MED\x04` (original MED 2.x). libopenmpt covers MMD0-3 only; format-coverage doc lists xmp as the backend but xmp is not built here and no test run was possible. Needs a new replayer or an xmp check.
- psf (PlayStation): psflib (MIT) is in tree but there is no PS1 CPU/SPU core. New replayer, big (Highly Experimental style cores have mixed licences).
- ast (All Sound Tracker, Feilei): format-coverage says "none (does not play)"; no replayer exists.
- sct: audit says nuade, NO SAMPLE; not tested.

## Proposed new rows
1. Prefix-as-extension misfire: the engine takes the file name prefix (`ay.`, `mp2.`, `mc.`, `sj.`, `bds.`) as a format even when the real suffix is claimed (pt3, usflib, pt2, instr). Decide the rule (suffix wins when claimed, prefix only for Amiga-style names with no claimed suffix) and fix once.
2. MAX AlloAllo level5: determine why mxe_module_parse refuses it (bad sample or player gap).
3. Music Editor `MED\x04` replayer (check xmp first; build xmp module here).
4. PSF/PS1 replayer (new third-party core, licence review).
5. All Sound Tracker (.ast) replayer: only a tiny OPL3 demo sample known; low value.
6. Verify zxtune claims (stp, psm, sct) once a SELECTA_ZXTUNE_SRC checkout is available.
