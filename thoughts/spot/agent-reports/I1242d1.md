## ABI rule followed
`sel_voice_state` is an out-struct filled by the host; it has no `size` field and is not in the T6 golden (the goldens pin only `sel_voices`, unchanged, so `abi-voices-layout` still passes). The only rule that exists is append-only, followed. A plugin binary built against the old header that passes its smaller struct to a new host would be overwritten past its end: there is no size gate to prevent that. All plugins in the tree are built from this header (consumers: the nuade shim and nuade/adapter.c scan stub, found by grep of `sel_voice_state`); external prebuilt plugins, if any exist, need a rebuild. A real gate would need a `get_state_ex(size)` member appended to `sel_voices` (changes the pinned goldens); not done.

## Paula backend: does not count
Paula plays by DMA: samples, loops and queue transitions run in the chip, there is no software position and no mix loop, so wraps and frame cannot be counted in `paula_voices.c`. It reports 0 (documented in voices.h and asserted in the Paula unit test). Consequence: nuade drivers that need wraps (bendaglishsid and the 10 others) are still silent on the Amiga Paula path. Real fix there needs the AUDx interrupt (INTREQ audio bits) feeding a counter; not started. Listed as a follow-up.
