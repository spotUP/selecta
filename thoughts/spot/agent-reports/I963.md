# I963: compact MUI window does not use the full screen height

## Johan's observation (rig 2)
"the full height of the screen is not used by the app" / "the ui is still collapsed vertically leaving no room for the
lists make it use full height". uitree: screen 640x256, window at y 46, 640x184.

## Measurements
- Rig 3 (this agent): the screen is 800x600 RTG depth 24, not 640x256 AGA. The screen plan (mui_ui.c:571, map/mui_screen.c)
  keeps the Workbench mode, so the compact class (I949c) is not used there. Window: 800x600 at 0,0, the full screen. So the
  full-size layout fills its screen; the defect is specific to the compact class.
- ENV:MUI and ENVARC:MUI on rig 3 hold only TERM.config and DIGIBOOSTER.1.cfg, no Selecta window snapshot. Suspect
  "MUIA_Window_ID snapshot restores an old size" is ruled out on rig 3 (not checked on rig 2).
- The log file could not be read while Selecta ran (TYPE could not open RAM:mui-log.txt; file locked).
- No 640x256 AGA run was reached within budget: rig 3 has no AGA Workbench mode, and changing the rig's Workbench mode
  was out of scope. The 184-row number is Johan's, not re-measured.

## Cause (from the code, MUI group layout rules)
- The window asks MUIV_Window_Height_Screen(100) (plugins/ui/mui/mui_ui.c:3085). MUI clamps the window height to the root
  group's maximum height.
- Root VGroup: topbar, suggestion text, HGroup(sidebar, balance, main pages, balance, detail), player. A horizontal group's
  maximum height is the smallest maximum height of its children.
- In the compact class the sidebar is a rail (mui_sidebar_group, mui_ui.c ~965-1006): only door buttons (aabtn, bounded
  maximum height) and no stretchable child. The full sidebar ends in mui_sidebar_dyn, which appends an unbounded
  MUIC_Rectangle (mui_ui.c:943). So only in compact mode the rail caps the body row, and with it the window, at the doors'
  height plus the fixed rows. This matches 184 < 256 and matches rig 3 (non-compact) filling its screen.

## Fix
mui_ui.c:1000-1005: after the door loop, the rail branch adds a MUIC_Rectangle filler, the same as the full sidebar.
Non-rail path unchanged.

## Diagnostic kept
mui_ui.c ~3127: the ladder log line now prints the root's maximum height and the sidebar, main and detail slot maximum
heights, so the next rig run shows which panel caps the window.
