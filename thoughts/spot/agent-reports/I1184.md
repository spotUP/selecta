# I1184 text UI player basics

Design: the text UI binds every key of the shared action table (src/uimodel/actions.c k_actions) through
`txt_bindings_default` (src/uimodel/keybind.c). After the hand-written k_defaults, each table action with a key, a
protocol line that is not PREF_SET, a key `txt_key_parse` accepts and no existing text binding gets a TXT_CTX_ANY
binding whose action is the table `line`. `tui_key` already sends non-'@' actions to the engine, so no per-key code
was added to tui_local. Keys the text table already binds keep their meaning. PREF_SET rows (layout, viz) are left to I1185.

New table keys (desktop inherits them): M-4 shuffle on, M-5 shuffle off, M-1 repeat off, M-2 repeat all, M-3 repeat one.
Already in the table and now reachable in text: M-n / M-p album, M-Backspace queue clear, M-s queue shuffle,
M-r reshuffle, M-h like, C-b Stats hide, C-d Switch to Desktop, C-Enter Play.

Header: second line shows "Shuffle" only when random is on and "Repeat all|one" only when repeat is not off, so
existing screen goldens are unchanged.

Sentinel: SEL_UI_STAT_TABLE_ACTIONS / SEL_UI_STAT_TABLE_ACTION_LOG (tags 0x50F2/0x50F3) count and log the table lines
`tui_key` sent for a key matched through a shared-table row. selecta prints them at exit with the engine options.

Test: text-ui-shared-actions (tests/m3/text_shared_actions.cmake, keys a/b/c), three runs through the real selecta
binary with --exec and --keys. Asserts engine option state, the sentinel log, header words, and ui_closed id=text for C-d.
The keys-file driver gained Alt-<key> and Ctrl-<letter> tokens.

Revert proof: with the action-table loop in txt_bindings_default disabled (n = 0) the test fails
("missing 'options random=on repeat=all queue_count=1'"); restored it passes. text-ui-*, uimodel, actions, keys tests
pass; dui-fkeys and dui-mediakeys fail as before (intentional dui-red placeholders).

Open:
- C-Enter: a terminal sends the same byte for Enter and Ctrl-Enter, so the binding exists but is likely unreachable on a real terminal; not testable through keys.
- MUI: this agent did not build MUI. MUI is assumed to lack all of these keys (shuffle, repeat, albums, queue clear/shuffle/reshuffle, like, Stats hide, Play, Switch to Desktop) until its binding table is checked; the new M-1..M-5 defaults come from the shared table so MUI can pick them up the same way.
