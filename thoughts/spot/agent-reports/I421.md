# I421 ZXTune replayer plugin (agent report)

Branch worktree-agent-a43fb381009874e20. Mac only; Amiga not built.

## Result
- Plugin plugins/replayers/zxtune: RENDER replayer, GPL module (sel_zxtune.dylib, 2,906,352 bytes), built in-process from the same ZXTune revision as bbmp (e36902fe1cc06d9e73116db644b688708a7745d4) with bbmp's pt2/pt3 patches plus four Selecta patches (no-z80ex, no-ps2-bios, no-rar-vgmstream, no-libvgm, no-shared-ptr-unique for libc++ C++20).
- Gate: SELECTA_GPL_PLUGINS and not Amiga/Emscripten/Windows. Core stays MIT. LICENSE: GPL-3.0-or-later, notes ZXTune LGPL-3.0 and bbmp wrapper GPL-3.0-or-later.
- Extensions registered in src/platform/platform.c as ZX Spectrum (32 rows): the Spectrum tracker families (PT1/PT2/PT3, STC, STP, ASC, SQT, PSC, PSM, FTC, TXT/Vortex text, COP, DST, and others from the adapter list).
- Test zxtune-decode (label m3): `selecta-cli render` on a real PT3 (Speccy2.pt3) and a real PT2 (PITON.pt2); asserts replayer=zxtune (sentinel), frame count within 1 percent, WAV energy above threshold. PASS.
- Revert proof: same script with SELECTA_PLUGIN_PATH pointing at an empty dir: "FAIL: render failed", rc=1.

## Verified vs not
- Verified: PT3 and PT2 render non-silent through the top-level CLI render entry.
- Unverified: other formats (STC, ASC, SQT, PSC, COP, DST, ...) are registered and linked, but have no fixture; not played.
- Unverified: build_zxtune.sh patch+trim path from a clean checkout (build used a hand-edited checkout in scratch; scripts were edited to match, never re-run clean).
- ctest registration itself not run (script run directly with the same env); cmake config did include it.

## Amiga cost note
- Module size on Mac arm64: 2.9 MB (ZXTune trimmed to Spectrum/chiptune families). 68k estimate: 2 to 3.5 MB code, plus C++ runtime and exceptions; heavy for the 1.85 MB nuade-class budget.
- CPU: ZXTune AY/beeper emulation in C++ with floating point plus STL; Mac render is far faster than real time. On 68020 expect AY render near or above 100 percent of a 14 MHz CPU; 68060 likely OK. Not measured.
- Proposed exemption row: "I421 Amiga: zxtune not built for Amiga (GPL gate excludes SEL_AMIGA, 2.9 MB C++ module, no 68k toolchain proven for ZXTune). Follow-up: native Amiga AY players (PT3 player) or a slim AY-only core; revisit on 68060 tier."
