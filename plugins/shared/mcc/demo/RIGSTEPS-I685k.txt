RIGSTEPS I685k: UP-Demo final gate, rig 2 (run by the integrator, not by row I685k)

Build products (build/amiga/plugins/shared/mcc/):
  UP-Button.mcc UP-Text.mcc UP-Panel.mcc UP-Tabs.mcc UP-Balance.mcc UP-Slider.mcc
  UP-Progress.mcc UP-Cycle.mcc UP-Field.mcc UP-Scroller.mcc UP-List.mcc   (11 classes)
  UP-MCC.mcp      preferences class
  UP-Demo         the demo program
  up-mcc.library  shared support library (target up_mcc_library; build it with: cmake --build build/amiga --target up_mcc_library)

1. Start rig 2 with --ram 256 and --purpose "<session>: UP-Demo class check". Keep audio off.
2. Copy to the rig:
     the 11 UP-*.mcc files and UP-MCC.mcp  ->  MUI:Libs/mui/
     up-mcc.library                        ->  LIBS:
     UP-Demo                               ->  RAM:
   (Install-AA from row I685h can do the first two copies; use it if present.)
3. In an Amiga shell on the rig:
     RAM:UP-Demo QUIT
   QUIT opens and disposes every class without showing the window. Without QUIT the window stays open about 3 seconds.
4. PASS:
     11 lines "[OK] <class> from MUI:Libs/mui (origin 0x........)", origin non-zero, one per class,
     then exit code 0 (Amiga shell: "Echo $RC" gives 0).
   FAIL: any "[ERROR] <class>" line, or exit code 20. A missing .mcc, a missing up-mcc.library or a class that
   fails to create all give [ERROR] for that class.
5. Stop the rig after the last command (rig.py stop) and delete its build directory.

Not covered here: gate item 2 (theme reload from UP-MCC.mcp), deferred to row I685n. Gate item 3 (PLAIN backend,
ttengine removed) and item 5 (rig-mui-* suite with static classes) are rig runs for the integrator.
